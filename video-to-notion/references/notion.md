# Notion 写入、校验与恢复

通过当前会话提供的 Notion 工具操作，名字与参数以实际工具描述为准。没有连接时返回 [配置指南](setup.md)。

## 写入准备

- 如工具要求，先通过 Notion fetch 读取 `notion://docs/enhanced-markdown-spec`，不能把该 URI 发给普通网页抓取器。
- 父页面：读取用户指定页面，使用其 page ID。
- 数据库：先 fetch 数据库取得 data source ID 和 schema，按真实标题字段和属性类型创建记录。不要把数据库 ID 当作 page ID，不擅自修改 schema。
- 未指定位置：当前 `create_pages` 支持时使用 `creation_mode: "draft"`，且不同时传 parent；此模式创建私人草稿。其他连接不支持时询问位置。
- 标题放在 properties，正文不再重复顶层标题。文章使用普通文档模式，不设为 Notion Skill。

## 创建与核验

先本地完成全文，创建一次文章页面。只保存用户所需文章；平台封面默认尝试作为头图，正文截图仅用户明确要求时加入，不默认上传整个视频、音频、逐字稿或全部核对截图。图片按工具真实上传能力插入；本地文件路径不是 Notion 可访问的图片 URL。

在 `~/.local/skill-state/video-to-notion/data/<唯一任务目录>/record.md` 保留来源标识、文章路径、目标、创建/核验状态和返回的 page ID/URL。这是恢复与避免重复创建所需的长期记录，不能放进 `cache/`，也不能随媒体缓存清理。若用户禁止任何本地保存，则在当前会话保留这些信息并说明跨会话恢复受限。成功后回读页面，比对标题、各章节、末尾来源和关键时间点；返回截断或未知 block 时按工具支持继续读取，不能把不可见部分判为已验证。

文章超出工具单次限制时，按当前工具支持的分段写入方式处理，并记录已写入章节；没有这种能力时保留本地全文并说明限制，不能静默截短正文。

## 图片交付（平台头图与按需正文配图）

先按 [封面/选帧与本地保存](extraction.md) 区分平台封面与正文配图，不自动上传用于内部理解的全部截图。根据当前工具描述检查本地文件上传、返回文件引用和插图能力；可用时按真实参数上传选中图片，再在对应段落插入，配简短主题说明和真实时间点。不能编造 upload 工具或把本地路径当可访问 URL；已有用户授权且确实可访问的图片地址可按工具规则引用，不为获得 URL 擅自上传公共图床。

记录已上传图片与返回引用，写入结果不明时先检查，避免重复上传/插入。回读核对图片块、对应段落与说明；若只能确认块存在而无法确认图片呈现，明确标为“图片块已写入，显示未验证”。只有实际查看确认图片可访问/显示才报告相应验证通过，不能凭上传成功称整篇已核验。

工具没有所需能力或上传失败时保留含相对图片链接的本地文章与图片；可按原授权保存文字版到 Notion，明确“本地有配图，Notion 尚未插图”及下一步，不把原文或已有页面清空。配图失败不丢失文字和来源材料。

结束时将写入与回读分别同步到 record 顶部当前状态；页面已写入但未回读不得合称已核验，材料边界未核实不抹去页面写入与回读的实际成功结果。

## 失败与重复运行

- 创建请求明确失败且未创建页面：修复已知问题后再试一次。
- 超时或返回状态不明：先检查异步任务、已返回的 page ID，或在指定目标中用文章标题/来源核实是否已创建；找不到不能自动断言“没有创建”。无法确认时停止重试并告知。
- 部分章节写入成功：使用已知 page ID 恢复，先回读避免重复追加。
- 再次处理同一来源：优先用本地任务记录和目标范围内搜索确认已有文章；询问更新还是新建，除非用户已指定。不要覆盖用户后来补充的内容。
- Notion 失败不影响本地文章交付；明确区分文章已写好与已保存到 Notion。
