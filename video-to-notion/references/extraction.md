# 字幕、音频与画面提取

命令是模板；把变量设为本次真实输入。`TASK_DIR` 是 `~/.local/skill-state/video-to-notion/cache/<唯一任务目录>/` 的媒体缓存；`SUBTITLE_DIR` 和 `ASR_DIR` 分别是 `data/<同一任务目录>/sources/<新提取批次>/subtitles/` 与 `asr/`；`MODEL_DIR` 是配置阶段确认的模型目录。执行前展开 `~` 为真实主目录，创建不存在的新批次并确认可写，使用绝对路径。原始字幕/转录直接进入长期目录，清洗稿另存，详见 [材料保存与复用](materials.md)。不要把用户输入拼成 shell 代码。先读当前版本 `--help`，仅输出必要状态，元数据中可能含私人信息。

## 命令探测与结果判断

先用 `command -v` 或文件存在/可执行检查确定实际命令；隔离环境路径不存在时记录“未安装/路径不可用”，不要先执行虚构路径制造报错。必要帮助探测与正式提取分开执行并分别查看 stdout、stderr、退出码及产物，避免组合命令掩盖是哪一步返回非零。

`rg` 返回 1 通常表示无匹配，返回 2 等才按实际错误处理；查询无结果不是提取失败。部分工具 `--help` 可能打印完整帮助后返回非零，只有核对该版本的实际行为/帮助输出后才视为探测结果，不能普遍忽略非零码。正式转录非零、产物缺失/损坏、权限错误仍须处理并保留诊断；帮助可打印不证明正式功能可用。命令不存在时按配置指南准备或说明阻碍，不把依赖缺失误称 Skill 业务缺陷。

## 原始文本数据的可读性

用户提供文件和工具原输出字节保持不变。文本材料应提供 UTF-8 可直接阅读的入口；已有可读的 SRT/VTT 无需转成 JSON。JSON 若中文被转义或缺少排版，在同一 `sources/` 批次另存 `<原文件名>.readable.json`，使用 `ensure_ascii=False`、`indent=2` 和 UTF-8，不覆盖原输出。记录两者对应关系，交付优先链接可读视图，并保留原文件入口。

先用 JSON 解析器读取，再序列化到不存在的新文件；不要字符串替换或通用转义解码，以免破坏引号、换行或反斜杠。重新解析视图，核对与原数据结构及全部值一致（含字段、分段、时间戳），抽查中文显示，并确认原文件未变；失败时报告原因，保留原文件，不将失败视图当成有效结果。可读视图只改变编码与排版，不清洗、翻译或校订。遇到重复键或解析器不能无损保留的数值等内容时，停止转换并说明限制，不能静默丢字段或改值。

## URL 字幕

以下 `yt-dlp`、`ffmpeg`、`ffprobe`、`llama-funasr-sensevoice` 代表配置阶段实际确认的命令；若安装在隔离环境，以对应绝对路径调用，不要求用户手动激活环境。

确认输入是单视频 URL。`--no-playlist` 只针对同时指向视频与播放列表的链接，不能阻止所有集合或 B站分 P 扩展；先确认具体分 P，必要时使用已核实的条目选择参数。

```bash
yt-dlp --ignore-config --no-playlist --list-subs -- "$VIDEO_URL"
```

从返回列表选真实存在的语言标识。人工字幕优先，自动字幕其次，不默认下载所有语言：

```bash
yt-dlp --ignore-config --no-playlist --skip-download --write-subs --sub-langs "$SUB_LANG" --sub-format 'vtt/srt/best' -P "$SUBTITLE_DIR" -o '%(id)s.%(ext)s' -- "$VIDEO_URL"
```

无人工字幕时将 `--write-subs` 换成 `--write-auto-subs`，明确记录自动字幕来源。程序退出成功但目录没有字幕文件，仍属于没有取得字幕。读取前确认文件非空、时间轴正常。

将标题、作者、原始链接、时长和材料参考要求的提取信息记录到任务记录；不要上传完整下载器元数据。滚动字幕的相邻重复只能在 `derived/` 的副本中清理，不能覆盖原文件或全局去重而误删后文重复论证。

## 浏览器登录信息与系统提示

只有用户明确授权读取指定浏览器登录信息后才加 `--cookies-from-browser`。**在启动命令前**说明：macOS 上读取 Chrome Cookie 可能弹出系统钥匙串密码/授权窗，用于解密本机 Chrome Safe Storage 的登录信息；密码只在系统窗口由用户输入，不发给 Agent，不粘到聊天或日志。拒绝或取消会使需要登录的字幕提取失败或继续等待；未生成字幕不能称已取得。

用户拒绝、取消或选择替代路径时，先通过保存的进程会话向本次 yt-dlp 发中断并核实退出；必要时仅终止已确认属于本任务的等待子进程，不按名称批量杀掉其他任务。请用户取消仍显示的本次系统窗口；不能让授权请求悬挂着同时启动另一条登录提取。无法确认退出时报告阻碍，先不继续新提取。

等待进程退出后，按用户选择尝试无 Cookie 的公开音频下载和本地 SenseVoice，或使用用户提供的字幕。公开标题/时长可读不代表音频可下载；音频、转录环境或授权不足时如实报告，不承诺绕过登录必定成功。不私自导出 Cookie 文件、不收集密码。参见 [yt-dlp Cookie 实现](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/cookies.py)。

## 下载前按时长判断

仅在确需下载音频/视频时执行；有充分字幕且无需画面就不下载媒体。先用公开元数据核实时长，或对已有本地文件用 ffprobe。网络元数据命令以本机 `yt-dlp --help` 支持为准，例如：

```bash
yt-dlp --ignore-config --no-playlist --skip-download --print '%(duration)s' -- "$VIDEO_URL"
```

多条输出/分 P 先确认目标，不把其中一条时长套给整组。时长为有效非负秒数才可用于判断；空值、NA、异常结果或直播视为未能确认有限时长。

| 已核实的视频时长 | 下载决定 |
| --- | --- |
| 不超过 3600 秒（含 60 分钟） | 在任务授权内直接下载所需媒体，不另加文件大小阈值 |
| 超过 3600 秒 | 说明时长与下载用途，先询问本次是否下载；已有明确授权则不重复问 |
| 未知 | 先尝试核实；仍未知时说明情况并询问本次下载，不记成长期偏好 |

判断依据是目标视频时长，不按裁出短片段来绕过长视频询问。既有本地媒体不需要重新下载。此约定不授权读取浏览器 Cookie、下载模型或付费服务；模型仍按配置指南独立说明位置、体积与授权。需要登录才能取元数据时，先走上述浏览器授权分支，不能为查时长偷偷读取登录信息。

## 无字幕时的音频

先完成上述时长判断和实际磁盘检查；磁盘不足则报告，不自行编造大小阈值。只需语音时：

```bash
yt-dlp --ignore-config --no-playlist -f 'bestaudio/best' -x --audio-format wav -P "$TASK_DIR" -o '%(id)s.%(ext)s' -- "$VIDEO_URL"
```

对于本地视频，先检查媒体流：

```bash
ffprobe -v error -show_entries format=duration:stream=index,codec_type,codec_name -of json "$VIDEO_PATH"
ffmpeg -nostdin -n -i "$VIDEO_PATH" -vn -ac 1 -ar 16000 "$TASK_DIR/audio.wav"
```

检查内嵌字幕格式后再决定是否提取；图像字幕不能直接当成文本字幕。没有音轨时转为画面分析，不能继续运行空音频转录。

## SenseVoice 本地转录

默认使用 [FunASR llama.cpp / GGUF](https://www.funasr.com/llama-cpp.html) 的 SenseVoiceSmall。先核对 [上游运行说明](https://github.com/modelscope/FunASR/tree/main/runtime/llama.cpp) 与本机 `--help`，确认支持 `-m`、`--vad`、`-a`、`--srt`。不是通用 llama.cpp 的聊天命令，也不套用 Whisper 参数。

```bash
"$SENSEVOICE_BIN" -m "$SENSEVOICE_MODEL" --vad "$VAD_MODEL" -a "$TASK_DIR/audio.wav" --srt > "$ASR_DIR/transcript.srt" 2> "$ASR_DIR/diagnostics.txt"
```

变量均为配置时核实的绝对路径；ASR_DIR 必须是新建批次，输出文件存在则停止，不能覆盖。保留原始 SRT、诊断与模型/运行时版本记录。检查退出码、文件非空、SRT 可解析、时间覆盖及缺口后才认定转录完成。FSMN-VAD 提供分段时间；没有 VAD 可能仅输出覆盖全段的一条字幕，不能声称有逐句定位或说话人分离。长音频外部分段时保留起点和原始输出，时间轴合并另存 derived。

上游网页示例与仓库下载脚本可能选择不同量化档或文件名；使用实际下载清单和本机帮助，不硬编码猜测。运行时缺失、平台不支持或不支持所需输出时，保留材料并说明下一步；未经用户选择不改用其他模型或上传音频。

## 关键画面

需要画面时按上述时长规则获取对应视频文件；仅下载音频无法提取画面。根据章节和具体讲解定位，不用固定几张截图代替完整视频理解：

```bash
ffmpeg -nostdin -n -ss "$TIMESTAMP" -i "$VIDEO_PATH" -frames:v 1 "$TASK_DIR/frame-001.png"
```

少量必要关键帧实际查看，已看清且仍可复用的图片不反复查看。预计理解内容需要大量视觉核对时，**开始批量识别前**说明预计图片数量/时间范围、为什么字幕不足、会增加图像输入与推理 token，并给出可减少查看数量/范围的方案；耗时仅作补充，取得用户同意后再做。无法准确估算 token 就明确未知，不用耗时代替 token 说明，不承诺未测量的精确消耗，也不能分拆成很多小批规避确认。

用户不愿大量识别时，说明可先仅依据字幕/音频整理，并在文章中明确视觉内容未核对；画面决定的代码/图表结论不补造。纯视觉视频没有必要证据则停止相关内容写作。少量图不足以覆盖全片时不能以几张图声称完整理解；工具能力本身不足也如实说明。

### 平台封面作为头图

B站/YouTube 链接默认尝试从本次实际视频元信息取得封面，核对视频 ID/分 P、标题与来源，确认图片属于目标视频后才使用；不要从搜索结果挑相似图片。仅获取必要元信息和封面，不为头图下载完整视频。多个分 P 共用主封面时如实记录，不冒称该分 P 独有封面。

选择可核实、分辨率适合阅读的封面资源；优先用平台元信息、目标视频 ID 与文件有效性确认，不为插入封面默认调用模型看图。只有归属或可用性确需视觉判断时才少量核验；拿不到、损坏或无法确认归属就省略，不造图。下载到 `sources/<新批次>/images/cover.<实际格式>`，保留原文件；record 记录视频身份、去敏来源 URL、获取时间、相对路径和用途“平台封面/文章头图”，index 的 sources 包含对应材料目录。不得把带签名/令牌的图片 URL 直接写入索引或文章；需要时仅保留可安全分享的来源，敏感部分省略。

下载或上传封面本身不等于模型视觉识别，不把两者成本混为一谈。本地 Markdown 在正文前引用本地封面。Notion 优先用实际上传能力获得可用引用；只有确认稳定且允许访问的非敏感 URL 才直接引用，不能把临时签名链接当长期图片。能力不足或失败保留本地封面、说明 Notion 暂无头图，文章照常交付。这里的头图可用正文开头图片块实现；只有工具实际支持页面 cover 属性时才设置，不虚构字段。本地视频没有可确认封面时不随机取帧冒充官方封面。

### 用户要求正文配图时

平台封面头图之外，只有用户明确要求正文配图才把截图加入文章，阅读材料所需的画面核对不等于自动配图。根据字幕定点选择 1–3 张，优先复用已查看、信息清楚且与论点直接相关的关键图表；没有合适帧时只在候选时间附近选少量清晰帧，不为配图全片密集抽帧。不添加只重复正文、模糊、过渡或被遮挡的截图；找不到合适图片就说明，不凑数量。

实际查看候选并核对文字/图表可读性，记录主题、真实时间点与对应段落；不得靠文件名判定图片内容。选中图片长期保存到新建 `sources/<批次>/images/`，与原始材料一起留存；正文用 Markdown 相对图片路径保存本地配图。上传前检查图片不含不必要的账号、通知或其他私人信息；处理过的副本另存 derived，原图不覆盖。按 [Notion 写入](notion.md) 核实上传能力、插入与回读结果，不承诺固定图像 token 或成本。

## 失败处理

- 登录限制、平台风控、地区限制：说明实际错误，优先让用户提供可读的视频或字幕。只在用户明确授权后使用指定浏览器或 cookie 文件；不自行读取浏览器凭据。
- 网络失败：遵循运行环境的网络权限机制，不无限重试；同一错误一次有依据的修复后仍失败就报告。
- 文件缺失或媒体损坏：报告已验证的路径或流问题，保留原文件。
- 部分字幕缺失：转录缺失区间；无法补齐则明确标记文章覆盖范围。
