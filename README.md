# video-to-notion

将 B站、YouTube 链接或本地视频整理为中文文章并保存到 Notion 的 Codex Skill。
默认忠实保留观点、论证与例子，去掉口语重复。

把本 ZIP 交给有本地文件操作能力的 Codex，并说：

> 请按包内 USAGE.md 安装或更新 video-to-notion。先比较并备份旧安装，保留全部用户数据。安装后验证文件；先不要下载模型或处理视频，需要我登录或授权时再说明下一步。

从 [使用指南](USAGE.md) 开始。只安装 `video-to-notion/` 文件夹；
Notion 授权及字幕、转录环境按需引导配置，交付包不含账号或个人状态。
